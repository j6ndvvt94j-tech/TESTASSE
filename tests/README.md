# Tests

Ce dossier accueillera les protocoles et résultats d'essais du projet TESTASSE.

Chaque résultat publié devrait préciser au minimum le matériel utilisé, la géométrie de la pièce, la position des capteurs et transducteurs, la bande de fréquence, les niveaux acoustiques, les paramètres DSP et les conditions de mesure afin de permettre la reproduction de l'expérience.
